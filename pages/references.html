References

  1. Biryukov, A., Dinu, D., Khovratovich, D. Argon2: the Memory-Hard Function for Password Hashing and Other Applications — the PHC winner's specification. password-hashing.net
  2. RFC 9106: Memory-Hard Functions for Password Hashing and Proof-of-Work — the IETF standard, including recommended parameter sets. rfc-editor.org/rfc/rfc9106
  3. OWASP Foundation, Password Storage Cheat Sheet — current recommended minimum parameters (Argon2id m=19 MiB, t=2, p=1). owasp.org/www-community/password-storage
  4. Provos, N., Mazières, D. (1999). A Future-Adaptable Password Scheme (bcrypt), USENIX ATC.
  5. Percival, C. (2009). Stronger Key Derivation via Sequential Memory-Hard Functions (scrypt), BSDCan.
  6. Kaliski, B. RFC 2898 / PKCS #5 v2.0 — PBKDF2 specification.
  7. hash-wasm — the WebAssembly library powering this lab's genuine in-browser hashing. github.com/Daninet/hash-wasm
