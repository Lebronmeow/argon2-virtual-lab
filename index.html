Argon2 — Memory-Hard Password Hashing

Welcome to the Argon2 Virtual Lab. This laboratory provides an interactive experiment on Argon2, the winner of the Password Hashing Competition (2015) and the current state-of-the-art for password storage. Argon2 is a memory-hard key derivation function: unlike fast hashes such as MD5 or SHA-256, it is deliberately designed to consume large amounts of memory, which makes massively parallel hardware attacks (GPUs, ASICs) economically impractical.

The lab offers three variants of the function — Argon2d (data-dependent addressing, maximum GPU resistance), Argon2i (data-independent addressing, side-channel safe) and Argon2id (hybrid, recommended for password storage) — and lets you experiment with all of them in the browser: tune the cost parameters, watch the internal memory-fill process, verify how salting defeats rainbow tables, and benchmark real hashing times.

Objective

After performing this experiment, the student will be able to:

  1. Explain why plain cryptographic hashes are unsuitable for password storage, and how offline cracking exploits their speed.
  2. Describe the internal design of Argon2: theBlake2b compression function, memory blocks, lanes, passes, and the two addressing modes (data-dependent and data-independent).
  3. Configure the three cost parameters — memory cost m, time cost (iterations) t and parallelism p — and reason about their security / usability trade-off.
  4. Demonstrate the role of the salt and compare a salted vs. unsalted pipeline against a simulated rainbow-table attack.
  5. Evaluate real-world performance by benchmarking Argon2id against PBKDF2 and selecting parameters for a target hashing time (e.g. OWASP's ≈19 MiB / 2 iterations / 1 lane minimum or the 600 ms interactive target).

Target Audience

  • Undergraduate students — courses on Cryptography and System Security (e.g. Mumbai University TE COMPS CSS, CSE/IT curricula covering password hardening and key derivation functions).
  • Postgraduate scholars — studying memory-hard functions, side-channel countermeasures and password-cracking resistance.
  • Faculty & evaluators — demonstrating practical secure password storage and the economics of brute-force attacks.
  • Practicing developers — anyone who stores user passwords and must choose real Argon2 parameters.

Quick Start

This is a fully static site — no backend, no installation. Either open the pages directly, or serve the folder with any static server:

# macOS / Linux
python3 -m http.server 8000

# Windows (PowerShell)
py -m http.server 8000

Then open http://localhost:8000 and navigate to the Simulation.

Note: the simulation uses the hash-wasm library (loaded from a CDN) to perform genuine Argon2id/i/d hashing in your browser. An internet connection is required for the hashing library; everything else works offline.
